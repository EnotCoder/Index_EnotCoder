# 🦝 Сайт EnotCoder

Одностраничное портфолио с упором на GitHub-проекты. Чистый HTML + CSS + JS,
без фреймворков и сборки.

Сайт состоит из трёх разделов:

| № | Раздел | Что внутри |
|---|--------|-----------|
| 01 | О себе | текст, терминал, чипы стека |
| 02 | Галерея | картины в рамах + просмотрщик (полноэкранный, стрелки/свайпы) |
| 03 | Проекты | все репозитории, скрин фоном, иконка, комментарии |

Плюс герой со статистикой, блок контактов и подвал.

## Структура

```
index.html          разметка
assets/
  style.css         стили (~40 КБ)
  script.js         логика и анимации (~47 КБ)
  logo.webp         логотип, 37 КБ — основной
  logo.png          логотип, 263 КБ — запасной (браузеры без WebP)
  favicon-48.png    фавиконка 48×48, прозрачные углы
  favicon-32.png    фавиконка 32×32
  favicon-16.png    фавиконка 16×16
  apple-touch-icon.png  иконка 180×180 для iOS (свой фон, iOS не умеет прозрачность)
  comments.js         комментарии под проектами (~9 КБ)
  shots/               скрины игр и программ — фон карточки проекта (~140 КБ)
  picons/              иконки проектов 128×128 — бокс карточки (~48 КБ)
  pictures/            картины для галереи, webp 1400 px (~400 КБ)
backend/              API комментариев: Cloudflare Worker + D1
```

Итого ~1 МБ на всю страницу (галерея и шоты грузятся лениво).

Исходные `pictures/*.png` по 3 МБ в `.gitignore` — в репозиторий идут
только webp, которые реально показывает сайт.

Логотип — PNG/WebP с альфа-каналом: круг, углы прозрачные. Поэтому
`border-radius` в вёрстке можно не ставить, а в фавиконках нет чёрных углов.

## Как запустить

```sh
# просто открой index.html в браузере
xdg-open index.html

# или подними локальный сервер
python3 -m http.server 8000
```

## Публикация на GitHub Pages

```sh
git init
git add .
git commit -m "сайт"
git branch -M main
git remote add origin https://github.com/EnotCoder/EnotCoder.github.io.git
git push -u origin main
```

Затем в репозитории: **Settings → Pages → Source: `main` / `/ (root)`**.
Адрес будет `https://enotcoder.github.io`.

## Данные о проектах

В `script.js` есть массив `SNAPSHOT` — все 10 репозиториев с описаниями,
написанными по README каждого проекта. Сайт работает офлайн на этих данных.

При открытии страницы дополнительно делается запрос к GitHub API:
`api.github.com/users/EnotCoder/repos`. Если он проходит — обновляются
звёзды, форки, даты и список репозиториев, а счётчики в шапке пересчитываются.
Если нет (нет сети, лимит 60 запросов в час, offline) — остаётся снимок,
и в блоке статистики появляется пометка об этом.

Чтобы зафиксировать новый снимок вручную, обнови цифры в `SNAPSHOT`.

## Скрины и иконки проектов

У каждого проекта в `SNAPSHOT` есть три необязательных поля:

```js
shot: 'cys',      // файл assets/shots/cys.webp — фон строки
icon: 'cys',      // файл assets/picons/cys.webp — иконка слева
```

- `shot` кладут в `assets/shots/`, ширина 1200 px, WebP ~70 — это фон строки,
  он затемняется градиентом слева, чтобы текст читался, и проявляется на hover.
- `icon` кладут в `assets/picons/`, квадрат 128 px, WebP ~88. Если поля нет,
  в боксе остаётся сокращение языка.
- Скрин и иконка живут только в `SNAPSHOT` — при обновлении через GitHub API
  эти поля подставляются из снимка (см. маппинг в `loadGitHub`).

Скрин бери так, чтобы он читался в горизонтальной полосе: важная часть —
по центру или сверху, крупные надписи лучше не оставлять в середине кадра.

## Галерея

Работы описаны в `script.js`, массив `GALLERY`:

```js
{
  src: 'assets/pictures/picture_one.webp',
  w: 1400, h: 1895,                     // размеры файла, чтобы не было прыжков
  title: 'Енот в рыцарских доспехах',
  note: 'Художественный портрет, 1078 × 1459',
}
```

Раскладка считается в JS (`layoutGallery`): полотна набираются в строку слева
направо, пока строка влезает в ширину; у всех в строке **высота одинаковая**,
а ширина считается по пропорции картины. Строка центрируется, максимум 400 px
(на телефоне 420 px), при изменении окна всё пересчитывается.

Как добавить картину:

1. положить файл в `assets/pictures/`
2. сделать webp шириной 1400 px, quality ~74 — исходник можно не класть,
   `pictures/*.png` в `.gitignore`
3. дописать объект в `GALLERY`

Пропорции берутся из полей `w` и `h` — важно, чтобы они совпадали с реальным
файлом, иначе картинку чуть прижмёт по краям.

Клик по полотну открывает просмотрщик: стрелки и точки, `Esc` закрывает,
на телефоне — свайп влево/вправо, свайп вниз закрывает. Счётчик «2 полотен»
в шапке раздела считается сам.

## Комментарии

Frontend — `assets/comments.js`, отдельно от `script.js`. Он общается с API
по адресу `CONFIG.api` (самое начало файла):

```js
const CONFIG = {
  api: '',                 // ← сюда адрес бэкенда
  ...
}
```

**Пока адрес пустой, всё работает в режиме localStorage:** форма, счётчик,
список, «только что / 3 мин назад» — всё на месте, но записи остаются
в этом браузере. У кнопки «Комментарии» в этом режиме плашка `local`.
Если адрес указан, но API не отвечает — плашка прячется, а вместо неё
жёлтая подсказка, и сайт не падает.

**Чтобы комментарии стали общими**, подними бэкенд: `backend/README.md`
(Cloudflare Workers + D1, бесплатно, 15 минут). Достаточно реализовать
четыре метода из контракта там — фронтенд трогать не придётся.

Защита от мусота: honeypot, лимит 6 комментариев в час с IP, санитайзер,
экранирование на выводе, удаление по токену.

## Анимации

- сеть частиц на canvas с реакцией на курсор и параллаксом
- наклон логотипа за курсором в 3D, вращающиеся кольца, пульсация ореола
- эффект «расшифровки» в заголовках (привязан ко времени, не к кадрам)
- печатающийся текст в подзаголовке
- счётчики, растущие при появлении
- появление секций и карточек по скроллу
- 3D-наклон карточек, магнитные кнопки, блик и подсветка за курсором
- прогресс прокрутки в шапке и кольцо на кнопке «наверх»
- пасхалка: 5 кликов по логотипу

Всё это отключается через `prefers-reduced-motion`, мобильные устройства
получают упрощённые версии эффектов.
