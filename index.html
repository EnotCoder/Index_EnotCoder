01 обо мне

Пишу то, чем сам пользуюсь

Начал с Godot — делал 2D-игры и кликеры. Потом затянуло в Rust: захотелось самому разобраться, как устроен рендер, и написать несколько проектов на wgpu напрямую, без игровых движков.

Теперь в стеке Bevy для быстрых прототипов, wgpu для 2D-песощниц, egui для редакторов и Godot для игр, которые хочется довести до публикации. Отдельно копаюсь в C++ — форк движка, OpenGL, рендер.

Небольшую часть кода пишу для себя: ltm_list — набор CLI, без которого уже неудобно, и MyArch — тема лаунчера под мой тайловый WM.
